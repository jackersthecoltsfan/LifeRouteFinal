# Documentation archive

This directory preserves superseded handoffs, checkpoint contracts, and build
history for archaeology. It is not current engineering or release guidance.

- `handoffs/`: historical v0.x handoffs, specifications, and control-chat notes.
- `checkpoints/`: historical native rebuild checkpoint reports.
- `build106-canonical-capture.md`: evidence for the one-time canonical capture.

Current contributors should begin with root `LIFEROUTE_HANDOFF.md`, then
`docs/BUILD_ARCHITECTURE.md`, `APP_CREATION_PLAYBOOK.md`, and
`GITHUB_ACTIONS_RUNBOOK.md`.
