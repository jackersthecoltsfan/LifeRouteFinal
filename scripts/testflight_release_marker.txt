LifeRoute Apple-native AI TestFlight release requested after successful iOS build and web-preview validation.
Release source: a2c819c7eed58bef93ab3526d64ad36dd89960aa

This test build intentionally uses Apple-native intelligence only. The AI layer includes Apple Foundation Models for on-device language and planning tasks, Apple Vision for screenshot OCR and visual analysis, and Apple Image Playground where supported. No OpenAI, Anthropic, Gemini, or other cloud language-model provider is included in this test build.

Deterministic LifeRoute systems remain authoritative for calendar events, route/travel calculations, stop duration, departure timing, reminders, and other exact app data. The purpose of this release is to test Apple Intelligence availability, response quality, device performance, ABA note drafting from supplied facts, screenshot OCR, planning assistance, and graceful local fallback behavior before considering an optional cloud-AI provider.
